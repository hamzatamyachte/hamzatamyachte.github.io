# Hamza Tamyachte

Games and side projects: https://hamzatamyachte.github.io/

## Games

- [Hanoi](https://hamzatamyachte.github.io/iphone-hanoi/): move the tower, one disc at a time. Earn stars, coins and themes.
- [Dodge](https://hamzatamyachte.github.io/iphone-web-game/): dodge meteors, grab coins, unlock animal friends.

Made for iPhone. Open a game in Safari, tap Share, then "Add to Home Screen" to play full screen and offline.
